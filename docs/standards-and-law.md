# Standards and law, with sources and verification status

This page keeps the fixed wording used in the README (Appendix B of the design document), with the source and the verification status of each statement. It is
not legal advice. Statements marked partly verified are softened in the README, never asserted. This file is the only place where the forbidden phrases of the
README may be quoted: for example "WCAG compliant", "fully compliant", "fixes all", "first tool", "proves every fix", "nothing else broke" and "no new failure appeared".

## Forbidden in the README

Tested by `tests/repo/conventions.unit.test.ts` (case-insensitive, terms assembled at run time): the compliance phrases above for WCAG, EAA and LBI, "fixes all",
"first tool", "proves every fix", "existing tools report", the overlay generalizations, "nothing else broke", "nothing new appeared", "no new failure appeared",
"break something else" and a disclaimer about Evinced. The gate sees axe and keyboard findings only, so the README says "no new detectable failure".
